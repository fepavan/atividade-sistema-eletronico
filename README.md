# 🏦 GEN-CAIXA — Sistema de Caixa Eletrônico em Python

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen?style=for-the-badge)

O **GEN-CAIXA** é uma aplicação interativa desenvolvida em Python que simula as operações essenciais de um caixa eletrônico real. O programa permite que o usuário gerencie seu saldo dinamicamente por meio de depósitos, saques e consultas, tudo de forma segura e com validações em tempo real.

---

## ✨ Funcionalidades

- **💵 Depósito:** Permite adicionar fundos ao saldo inicial, validando se o valor inserido é maior que zero.
- **💸 Saque:** Realiza a retirada de valores do saldo, com validação de saldo suficiente e bloqueio para valores negativos ou zerados.
- **📊 Consulta de Saldo:** Exibe o saldo consolidado atualizado instantaneamente.
- **🔄 Menu Interativo:** Execução contínua em loop utilizando comandos intuitivos até que o usuário decida encerrar a sessão.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Python 3](https://www.python.org/)
- **Paradigma:** Programação Estruturada (com modularização por funções)

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
Ter o Python 3 instalado em sua máquina ou utilizar um ambiente online como o Google Colab.

### Execução
1. Copie o código do arquivo principal ou execute a célula de código acima.
2. Informe o **Saldo Inicial** desejado.
3. Navegue utilizando as opções numéricas do menu:
   - `1` para ver seu saldo.
   - `2` para realizar depósitos.
   - `3` para realizar saques.
   - `4` para finalizar a operação e sair com segurança.
